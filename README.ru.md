## О проекте

Репозиторий содержит детерминированный обучающий набор данных, генератор, код модели, средства оценки и опубликованные артефакты локальной системы понимания QSO для Game-Morse-Adventurer.

Это не универсальная диалоговая модель. Она классифицирует декодированный текст, подходящий для азбуки Морзе, чтобы игра определяла намерение, темы, значения, качество процедуры и возможность безопасно продолжить QSO.

## Политика данных

Все данные детерминированно создаются из синтетических шаблонов QSO. Сжатые копии и SHA-256 находятся в [`datasets/qso-semantics-v4`](./datasets/qso-semantics-v4), а [`DATASET.md`](./DATASET.md) описывает каждое фиксированное разбиение.

- Данные игроков, телеметрия, сохранения, сообщения и записи не используются.
- Журналы QSO и частные сообщения не собираются.
- Во время игры онлайн-сервис не требуется.
- Синтетические позывные и личности вымышлены; любые совпадения случайны.
- Генератор воспроизводит размеченные данные по документированным seed-значениям.

Контрольная точка обучалась 16 эпох на 100 000 примерах. Использовались 15 000 отдельных проверочных примеров и три независимых подтверждающих набора по 15 000 примеров с seed `90268741`, `90268742` и `90268743`.

## QsoSemanticFormer v0.4

`QsoSemanticFormer` — символьный Transformer из шести слоёв с 942 898 параметрами. Он выдаёт речевые действия, темы, поля значений на уровне символов, регистр, оценку процедуры и состояние безопасного продолжения.

Опубликованы контрольная точка PyTorch, эталон FP32 ONNX, CPU-модель INT8 ONNX, контракт среды выполнения, манифест и отчёты о соответствии, производительности и критериях выпуска.

Вышестоящий декодер PulseFormer не входит в репозиторий; он оценивается отдельно и не утверждён как функция игры.

## Воспроизведение

Требуется Python 3.11 или новее.

```bash
python -m pip install -e ".[export,test]"
python -m pytest
python scripts/export_semantic_dataset.py --all

python -m cw_pulseformer.train_semantic \
  --epochs 16 \
  --train-samples 100000 \
  --val-samples 15000 \
  --seed 20260805 \
  --output runs/semantic-v0.4
```

Команды оценки и экспорта, схемы и критерии выпуска описаны в [`MODEL_ARCHITECTURE.md`](./MODEL_ARCHITECTURE.md) и [`MODEL_CARD.md`](./MODEL_CARD.md).

## Ограничения

Результаты относятся к детерминированной синтетической области радиопроцедур, а не к произвольному диалогу, первичному декодированию Морзе, радиошуму, распространению или временным характеристикам оператора. Эти задачи выполняются отдельными слоями.

Текст в эфире ограничен английскими ASCII-сокращениями и романизированными значениями. Локализация интерфейса выполняется в игровом проекте.
